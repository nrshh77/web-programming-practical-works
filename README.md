## Інструкція з використання проєкту

### 1. Відкриття вебсайту

Проєкт розміщений на платформі GitHub Pages, тому його можна переглядати без встановлення додаткових програм.

Для відкриття сайту необхідно:
1. Перейти за посиланням: https://nrshh77.github.io/web-programming-practical-works/
2. Дочекатися завантаження головної сторінки.
3. Ознайомитися з основною інформацією, представленою на сайті.
4. Скористатися навігаційним меню для переходу між розділами.

На сайті доступні такі основні розділи:
- **Головна** — сторінка з інформацією про автора та навчальний проєкт.
- **Практичні роботи** — перелік виконаних завдань із вебпрограмування.
- **Індивідуальний проєкт** — інтерактивний список справ To-Do List.

### 2. Робота з розділом «Практичні роботи»

Для перегляду практичних завдань потрібно перейти до відповідного розділу через навігаційне меню.

У цьому розділі представлено вісім практичних робіт, які охоплюють основні теми вебпрограмування.

Кожна робота присвячена окремій технології або напрямку розробки:
1. HTML5 — створення структури вебсторінок.
2. CSS3 — оформлення та адаптивний дизайн.
3. JavaScript — робота з масивами та методами їх обробки.
4. DOM — взаємодія з HTML-елементами та обробка подій.
5. Fetch API — отримання інформації із зовнішніх джерел.
6. SQL — створення таблиць і робота з даними.
7. React — створення компонентів та передавання властивостей через Props.
8. React useState — керування станом компонентів.

Для ознайомлення з результатами необхідно відкрити відповідну практичну роботу та переглянути її реалізацію.

### 3. Використання індивідуального проєкту To-Do List

Індивідуальний проєкт являє собою інтерактивний список справ, призначений для планування повсякденних завдань та контролю їх виконання.

Для початку роботи необхідно перейти до розділу «Індивідуальний проєкт» за допомогою навігаційного меню або відкрити сторінку безпосередньо:

https://nrshh77.github.io/web-programming-practical-works/individual-project/

Після відкриття сторінки користувач побачить заголовок «Мій список справ», поле для введення нового завдання, кнопку додавання, фільтри та область відображення списку.

#### 3.1. Додавання нового завдання

Щоб створити нове завдання, необхідно:
1. Знайти текстове поле з підказкою «Введіть нове завдання...».
2. Натиснути на поле та ввести назву завдання.
3. Натиснути кнопку «Додати».
4. Після цього нове завдання з'явиться у списку.

Якщо поле залишити порожнім, завдання не буде додане. Перед збереженням програма перевіряє введений текст.

#### 3.2. Позначення завдання як виконаного

Для відстеження виконаних справ передбачено спеціальний прапорець біля кожного завдання.

Щоб позначити завдання як виконане:
1. Знайти потрібне завдання у списку.
2. Натиснути на прапорець біля нього.
3. Завдання отримає статус виконаного та змінить своє оформлення.

Якщо повторно натиснути на прапорець, завдання знову стане активним.

#### 3.3. Видалення завдання

Для видалення завдання потрібно:
1. Знайти завдання, яке більше не потрібне.
2. Натиснути кнопку «Видалити», розташовану поруч із ним.
3. Завдання буде видалене зі списку.

Після видалення список автоматично оновиться.

#### 3.4. Фільтрація завдань

Для зручного перегляду завдань у проєкті реалізовано три фільтри:

- **Усі** — відображає повний список завдань, незалежно від їхнього статусу.
- **Активні** — показує лише ті завдання, які ще не виконані.
- **Виконані** — відображає лише завдання, які були позначені як виконані.

Для використання фільтра достатньо натиснути відповідну кнопку. Список автоматично оновиться відповідно до вибраної категорії.

#### 3.5. Відображення кількості завдань

Під списком справ розташований лічильник, який показує:
- Загальну кількість створених завдань.
- Кількість активних, тобто ще не виконаних завдань.

Показники автоматично змінюються після додавання, видалення або позначення завдань як виконаних.

#### 3.6. Автоматичне збереження даних

Для збереження інформації використовується технологія LocalStorage.

Усі створені завдання автоматично записуються у локальне сховище браузера. Це дозволяє:
- Зберігати список справ після оновлення сторінки.
- Повторно відкривати проєкт без втрати збережених завдань.
- Зберігати статус виконання кожного завдання.
- Продовжувати роботу зі списком у тому самому браузері.

Дані зберігаються локально на пристрої користувача, тому вони не синхронізуються автоматично між різними браузерами або пристроями.

### 4. Рекомендації щодо використання

Для коректної роботи проєкту рекомендується:
- Використовувати сучасний браузер, наприклад Google Chrome, Mozilla Firefox або Microsoft Edge.
- Переконатися, що JavaScript увімкнений у браузері.
- Для збереження завдань використовувати той самий браузер.
- Не очищати дані сайту та LocalStorage, якщо потрібно зберегти створений список справ.
- Перевіряти правильність введення тексту перед додаванням завдання.

### 5. Запуск проєкту локально

За необхідності проєкт можна завантажити на комп'ютер та запустити локально.

Для цього потрібно:
1. Відкрити репозиторій на GitHub.
2. Завантажити його за допомогою кнопки **Code → Download ZIP** або клонувати через Git.
3. Розпакувати архів у потрібну папку.
4. Відкрити папку проєкту у редакторі коду, наприклад Visual Studio Code.
5. Для запуску основного сайту відкрити файл `index.html` у браузері.
6. Для перегляду індивідуального проєкту відкрити файл `individual-project/index.html`.

Для запуску React-проєкту необхідно мати встановлений Node.js. У терміналі в папці React-проєкту потрібно виконати:

```bash
npm install
npm run dev
```

Після запуску Vite надасть локальну адресу, за якою можна переглянути React-застосунок.

## Висновок

Розроблений проєкт об'єднує результати виконання практичних робіт із вебпрограмування та індивідуальний мініпроєкт.

Під час роботи було реалізовано вебсторінки, інтерактивні елементи, обробку даних, взаємодію з API, роботу з базами даних та використання компонентного підходу в React.

Індивідуальний To-Do List демонструє практичне застосування HTML, CSS та JavaScript для створення функціонального вебзастосунку з можливістю додавання, видалення, фільтрації та збереження завдань.

Проєкт призначений для демонстрації отриманих знань і навичок та може використовуватися як навчальна робота з дисципліни «Вебпрограмування».
